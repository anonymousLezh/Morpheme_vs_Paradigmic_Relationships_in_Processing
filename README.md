# Morpheme_vs_Paradigmic_Relationships_in_Processing

This repository contains all the data, experiments, materials, and statistical analyses used for the "Morpheme-to-morpheme vs. paradigmatic representations in lexical processing" paper, submitted to the Morphology Journal. 

- **data**: Raw data files (Participant IDs have been anonymized)
- **experiments**: Clickable versions of the experiments (see readme.md inside that folder for how to start the experiment)
- **materials**: csv files with all variables used in the statistical analysis
- **output**: Output of data preprocessing and PCA of variables
- **scripts**: All analysis scripts
